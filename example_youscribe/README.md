# PDPDFKit / Youscribe Example

First, you need to create a `secrets.json` file with `cp example.secrets.json secrets.json` and fill it with your own values.

Then, you can run the example with:

```
flutter run --dart-define-from-file=secrets.json
```

IDs:

- iOS: `com.youscribe.pspdfkit.example`
- Android: `com.youscribe.pspdfkit.example`
